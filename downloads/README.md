# Crystal Front Android — рекламное окно с отложенным закрытием

12 октября 2026. [Скачать APK 1.0.4-debug / code 5](crystal-front-android-rewarded-popup-code5.apk).

Откройте «Магазин» → «Смотреть тестовую рекламу → +170 Лучей». Поверх игры появляется рекламная карточка с затемнением и отсчётом в верхнем углу. Через 5 секунд активного просмотра появляется крестик. Окно остаётся открытым, пока вы не закроете его; после закрытия сохраняются 170 Лучей.

До конца отсчёта крестик, Back/Escape и нажатие вне карточки не закрывают показ. Уход в фон приостанавливает отсчёт, возврат продолжает его. Перезапуск во время незавершённого показа не даёт награду и не восстанавливает окно. После получения Лучей можно купить обычный бонус и проверить баланс/количество после перезапуска.

Это явно обозначенная локальная заглушка, без рекламного SDK и сетевого объявления. Точный внешний вид будущего реального объявления зависит от провайдера; он подключается через отдельный адаптер. Настоящий SDK и его поведение на телефоне ещё не интегрированы/не проверены.

Unit/regression и RU/EN mock-host UI при 390×844 и 844×390 прошли, включая раннее закрытие, паузу таймера, earned только после закрытия, покупку и сохранение. Отдельный smoke с обычными 5 секундами также прошёл. Это не проверка установленного APK на физическом устройстве.
