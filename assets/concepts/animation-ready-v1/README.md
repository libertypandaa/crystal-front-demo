# Animation-ready concept sheet v1

This folder contains approval assets for the next Crystal Front combat-screen visual pass.

- `source/single-crystals-frontier-chromakey.png` is the source concept sheet on green background.
- `alpha/single-crystals-frontier-alpha.png` is a quick transparency preview.

Note: the alpha preview is not a final sprite sheet. The green crystal is affected by chroma key cleanup, so production sprites should be exported with native transparency or separated per crystal color.
